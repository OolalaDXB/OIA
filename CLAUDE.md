# OIA · règles pour les sessions Claude Code

- Le dossier `prototypes/oia-prototype/` appartient à Lovable (branche
  `lovable/oia-visibility-prototype`). Aucune session Claude Code ne le
  modifie : ni édition, ni suppression, ni formatage, ni mise à jour de
  dépendances. Il arrive dans `main` uniquement par fusion de la branche
  Lovable, sans changement. Un défaut constaté dans ce dossier se signale
  (par exemple dans `docs/interface/`), il ne se corrige pas ici.
