# Prototype OIA Visibility

Copie ponctuelle du prototype Lovable, ajoutée séparément pour ne pas remplacer l’application existante. Aucun fichier .env, historique Git, configuration Supabase ou résultat de compilation n’est inclus. Ce transfert ne configure pas une synchronisation automatique avec Lovable.

## Lancer le prototype

Depuis ce dossier : `bun install`, puis `bun run dev`. Les données de démonstration restent dans `src/data/demo.ts`. Le fichier de routes généré est recréé par Vite.
